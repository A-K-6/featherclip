01 / macOS 13+

Install on your Mac

  1. Download the installer for your Mac: Apple Silicon / ARM64 for M-series Macs, or Intel / x86_64 for Intel Macs.
  2. Quit an older copy of FeatherClip if it’s running. Open the disk image and drag FeatherClip into Applications, replacing the older app.
  3. Open FeatherClip. Its clipboard icon lives in the menu bar.

These community builds are ad-hoc signed and aren’t Apple-notarized. If macOS blocks the first launch, follow Apple’s Open Anyway instructions in System Settings → Privacy & Security.

To use history, keep your destination app active and press ⌘⇧V. Search, use arrow keys, and press Enter—or click a clip. Shift+Enter or Shift-click copies without pasting.

Mac paste permissions

The popup closes, but nothing pastes

FeatherClip needs permission to send Paste to another app. Capture and copy can work without it.

  1. In FeatherClip, choose ••• → Enable direct paste.
  2. In System Settings → Privacy & Security → Accessibility, enable FeatherClip. Newer macOS calls this pane Device Control and Data Access.
  3. Quit and restart FeatherClip. Bring TextEdit or another destination app to the foreground, copy a short test sentence, delete it, open FeatherClip, and select that clip.
It’s already enabled, especially after an update

An old code signature can leave a stale entry behind. Select only FeatherClip in that permission list and remove it with the minus button. Add your installed FeatherClip.app again with the plus button, enable it, and restart the app. macOS may ask you to authenticate this change.

I see more than one FeatherClip

Quit FeatherClip and keep one installed copy in your chosen Applications folder. Move older installed copies to Trash, then open the copy you want to keep. Refresh its permission entry if needed.

A picture or file won’t paste

The destination must accept that content. Try a text editor for text, an image-capable editor for pictures, or Finder for files. File entries point to their original locations; moved or deleted files need to be copied again.

If the destination has closed or can’t regain focus, your clip stays copied. Use the destination’s normal Paste command.

02 / Ubuntu 24.04+ amd64

Install on Ubuntu

Download the .deb installer, open a terminal in its folder, and run: 

sudo apt install ./FeatherClip_{{VERSION}}_amd64.deb

Open FeatherClip from Applications. On X11, Ctrl+Alt+V opens the popup when the shortcut is available.

Default Ubuntu / GNOME Wayland

  1. Choose ••• → Enable GNOME integration in FeatherClip.
  2. If GNOME hasn’t discovered the bridge yet, log out and back in, then enable it again.
  3. In your desktop’s keyboard settings, add a custom shortcut for featherclip --toggle.

The included GNOME bridge provides clipboard access and previous-window paste locally. It stores no history and makes no network connections. GNOME 46 is exercised in CI; the extension declares compatibility with GNOME 45–51.

Another Wayland desktop

Support is best effort. Compositors with the clipboard data-control protocol can capture text and file references. Direct paste currently requires GNOME or X11, and image capture requires GNOME or X11. Use your normal Paste shortcut where direct paste isn’t supported.

Linux terminal apps use Ctrl+Shift+V for paste. Other apps generally use Ctrl+V.

Small by design

What’s remembered

  • Up to 30 unique clips, newest first, with a 24 MiB total retained payload limit.
  • Text up to 100 KiB; PNG/TIFF images up to 8 MiB. X11 uses PNG.
  • Up to 100 local file references / 100 KiB of reference metadata. Files remain at their original locations and are copied rather than cut.

History lives only in memory. It clears when you quit. Clear removes the history without changing your current system clipboard. Capture starts with new copies after launch, and copies made while paused aren’t backfilled.

Ordinary copied text can contain secrets. Pause before copying sensitive information. Known concealed markers are skipped on Mac and GNOME, but not every clipboard backend exposes them. OS swap/crash handling and other clipboard managers are outside FeatherClip’s control.

There are no accounts, analytics, or clipboard sync between devices. This website doesn’t read your clipboard, use cookies, load third-party scripts, or run analytics. It is hosted on GitHub Pages; GitHub’s privacy statement covers the hosting service.

Remove FeatherClip

Turn Start at login off and Quit first. On Mac, move the app from Applications to Trash. On Ubuntu: 

gnome-extensions disable featherclip@aeen.github
sudo apt remove feather-clip

No saved clipboard history needs removing. The optional Linux login item is ~/.config/autostart/featherclip.desktop.

Still stuck? Open an issue with your app version, OS, desktop/session, and steps to reproduce. Use sample content instead of private clipboard data.
